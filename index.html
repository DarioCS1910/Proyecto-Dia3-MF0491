Conceptos Clave del Dia

Box Model

Todo elemento HTML es una caja. Capas: margin > border > padding > content. Usar box-sizing: border-box para que el padding no aumente el tamano.

Colores CSS

Formatos: HEX (#ff0000), RGB (rgb(255,0,0)), RGBA (rgba(255,0,0,0.5)) donde el 4to valor es la opacidad entre 0 y 1.

Flexbox

Sistema de maquetacion 1D. Se activa con display: flex en el contenedor padre. Controla filas o columnas con justify-content y align-items.

justify-content

Controla el eje principal (horizontal en row): flex-start | flex-end | center | space-between | space-around | space-evenly.

align-items

Controla el eje cruzado (vertical en row): stretch (defecto) | flex-start | flex-end | center | baseline.

Unidades CSS

px: absoluto. %: relativo al padre. em: relativo al font-size del padre. rem: relativo al root html. vw/vh: % de la ventana.

Demo: Box Model en codigo

Estructura del Box Model (de afuera hacia adentro):

margin: 30px auto; /* espacio exterior */
border: 2px solid #333; /* borde */
padding: 20px; /* espacio interior */
width: 300px; /* contenido */
box-sizing: border-box; /* padding incluido en el ancho */
